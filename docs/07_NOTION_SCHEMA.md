# Notion schema

Create these databases in one private Sales OS page. Keep names stable for integration mapping.

| Database | Essential properties |
|---|---|
| Accounts | Name (title), Website, Country, Industry, Employee estimate, Business model, ERP status, Complexity, ICP score, Qualification, Next action, Sales angle, Owner, Last researched, Evidence (relation), Opportunities (relation) |
| Contacts | Name, Account (relation), Role, Email, LinkedIn, Influence, Status |
| Opportunities | Name, Account, Stage, Amount range, Close target, Health, Pain, Champion, Decision maker, Next action, Tasks (relation), Meetings (relation) |
| Meetings | Name, Account, Opportunity, Date, Attendees, Notes, Confirmed needs, Assumptions, Commitments, Next action |
| Activities | Name, Date, Type, Account, Opportunity, Outcome, Follow-up date |
| Tasks | Name, Due, Status, Priority, Account, Opportunity, Owner |
| ICP Definitions | Name, Countries, Industries, Employee range, Business models, Pains, Technology, Triggers, Version, Active |
| Research Evidence | Claim, Classification, Source URL, Source name, Confidence, Captured date, Account |
| Knowledge | Title, Type, Content / Drive link, Security tier, Tags, Last reviewed |

Statuses: Account qualification = Researching / Qualified / Review / Not a fit / Archived. Opportunity stage = Discovery / Qualified / Solution / Proposal / Negotiation / Won / Lost. Use Notion relations and rollups rather than copied company names.
