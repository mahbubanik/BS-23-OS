# Forms

Phase 1 ships New ICP and Research Company. The following later forms should be short Notion forms or an authenticated web form:

| Form | Required inputs | Default output |
|---|---|---|
| New lead | Account, name/role, source | Contact + task |
| Pre-meeting | Account, meeting date, attendees | Objectives, questions, hypotheses |
| Post-meeting capture | Notes, commitments, next date | Meeting + tasks + deal update |
| Quick activity | Type, account, outcome | Activity |
| Deal update | Stage, health, blocker, next action | Opportunity update |
| End-of-day | Completed, blocked, top 3 tomorrow | Activity summary + tasks |

Use selects for status/stage, defaults for owner/date, and voice-to-text where available. Never make users retype account data already stored.
