# Executive overview

BS23 Sales OS is one structured sales brain, beginning with research and qualification. The deployed MVP is a static, phone-first web page: define an ICP, find companies through normal web search, record evidence, score consistently, and save/export accounts. It needs no LLM or credentials.

The next controlled step is a private Notion workspace as the shared system of record. Scheduled and sensitive operations run server-side (GitHub Actions or serverless), never in the browser. This keeps Phase 1 reliable and near-zero cost.
