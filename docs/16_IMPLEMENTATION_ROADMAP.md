# Implementation roadmap

**Phase 0 — complete:** architecture, data model, scoring, security boundaries.

**Phase 1 — complete:** browser ICP vertical slice; test it on real accounts tomorrow.

**Phase 2 — in progress:** private Notion schema and secure account/evidence sync. The adapter is ready but cannot run until the user creates scoped Notion data sources and secrets. Lead/meeting capture remains intentionally blocked from browser storage because it may contain personal or client-sensitive information.

**Phase 3:** opportunity state, solution mapper, controlled communication drafting using the existing BS23 outreach rulebook.

**Phase 4:** Outlook Calendar/Mail connected daily operator and activity capture. Calendar access is read-only for preparation; mail starts as an approval-required draft.

**Phase 5:** weekly evidence-based improvement coach.

**Phase 6:** optional search API, approved enrichments, freshness/cache jobs, and human approval gates.

Do not start the next phase until the prior phase’s daily use and data quality are proven.
